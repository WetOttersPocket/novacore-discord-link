# 🌌 NovaCore Discord Link

## ✨ What it is

Scan the QR code in NovaCore (**Quick menu > Friends > Link Discord**) with your phone and sign in to Discord. No PC needed.

## 🔒 Privacy

- Requests the Discord `identify` scope only.
- Uses PKCE with no client secret on this page.
- Saves only your Discord ID and username against your Nova friend code.
- Unlink anytime from NovaCore.

## 🎮 What you get

- Your Discord name on your Nova friend card.
- Friend and Discord notifications.
- **Playing NovaCore** status.

## 🛠️ How it works

QR code → this page → Discord sign-in → back to your console.
